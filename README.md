# Nepal Flood 2026 Dashboard

This project presents an interactive dashboard for the 2026 Nepal flood disaster using official Government of Nepal data sources.

## What the dashboard shows
- Total affected people, displaced families, deaths, injuries, and missing persons
- Province-wise comparison of affected population
- Province-level relief camp and displacement snapshot
- Province filter for interactive analysis

## Run locally
Open `/home/runner/work/nepal_flood_2026/nepal_flood_2026/index.html` in a browser.

## Data source
Official flood situation reports from Government of Nepal agencies (Ministry of Home Affairs, Department of Hydrology and Meteorology, and NDRRMA).
